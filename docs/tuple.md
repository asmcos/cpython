# 元组和列表很像，区别是元组创建以后不能改。

用小括号创建，元素之间用逗号分开。只有一个元素时，必须写成 `(1,)`，否则只是普通括号。

```
t1 = (1, 2, 3, "a")

print(f"t1[0]: {t1[0]}")
print(f"t1[-1]: {t1[-1]}")
print(f"t1[2:4]: {t1[2:4]}")

t2 = (3, 4)
t3 = t1[:2] + t2
print(t3)

l = [1, 2, 3]
print(type(tuple(l)))

t = (1, 2, 3)
print(type(list(t)))
```

`f"..."` 是 Python 3.12 里最常用的字符串格式化写法，叫 f-string。花括号里的表达式会被算出来再拼进去。

元组不能改某一个位置：

```
t = (1, 2)
t[0] = "1"
```

这会报 `TypeError`。

可以删掉整个变量，但不能删元组里的某一个元素：

```
t = (1,)
del t
```

## 执行结果

```
t1[0]: 1
t1[-1]: a
t1[2:4]: (3, 'a')
(1, 2, 3, 4)
<class 'tuple'>
<class 'list'>
```

Python 3 里类型显示是 `<class 'tuple'>`，不再是 Python 2 的 `<type 'tuple'>`。
