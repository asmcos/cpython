# 智普教育 · jeapedu.com

2012 年，我做了智普教育 [jeapedu.com](https://jeapedu.com)。它是国内较早的 Python 培训机构。

这份教材专门写给刚入校的大学生。Python 易学，能很快体验到编程的趣味。当你以后再学其他语言，也可以拿 Python 来对照理解。

本站代码和例子开源：

* https://github.com/asmcos/cpython

## 教材分成两部分

请按顺序读。先把第一部分跑通，再进入第二部分。

### 第一部分：大学生 Python 入门

给第一次学编程的同学用。基于 **Python 3.12 及以上** 版本编写。

内容尽量简单，目标是：你会装环境、会写小程序、能看懂报错、能自己改例子。

* [第一部分导读](part1/index.md)

### 第二部分：金融科技学生学习大纲

给金融、金融工程、金融科技方向的同学用。默认你已经学完第一部分。

这一部分是学期大纲：学什么、按什么顺序学、每块练什么、期末做什么项目。

* [第二部分大纲](fintech/index.md)

## 环境要求

* Python **3.12 或更高**（3.13 也可以）
* 不要再用 Python 2，也不建议停留在 3.7 / 3.8
* 安装步骤见：[安装 Python 3.12](part1/install.md)
