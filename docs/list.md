# 列表

列表用方括号表示，里面可以放多个值，并且可以修改。

下标从 0 开始。`l1[3]` 是第 4 个元素。

```
l1 = [1, 2, 3, 4]

print(l1[3])
print(l1[0])

l2 = ["abc", "1", "hello", 1]

print(l2[0])
print(l2[-1])
```

列表里可以同时放字符串和数字。

## 执行结果

```
4
1
abc
1
```

用 `python examples/list.py` 运行。后面 [列表函数](list_func.md) 会讲 `append`、`pop`、`insert`。
