# 第一部分：大学生 Python 入门

这一部分给刚入校、第一次学编程的同学。学完以后，你应该能：

* 在自己的电脑上运行 Python 3.12
* 读懂变量、字符串、列表、字典
* 会写 `if`、`for`、函数
* 会读文件、处理报错、安装第三方库
* 看懂别人写的短脚本，并改一改

全部例子按 **Python 3.12 及以上** 来写。Python 3 默认就是 UTF-8，不再需要文件开头的 `#coding:utf-8`。

## 建议学法

1. 每一节先看文字，再自己把例子敲一遍。
2. 不要只看结果。改一个数字、改一个字符串，看输出怎么变。
3. 报错不要怕。把完整报错读一遍，再对照 [错误和异常](../error_except.md)、[调试](../debug.md)。
4. 第一遍读不懂的地方可以跳过，学完后面再回来。
